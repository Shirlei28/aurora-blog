这是博客的第一篇文章。

## 为什么从一个简单的静态博客开始

内容本身才是博客最重要的资产。把文章写成 Markdown，把代码放在 Git，把页面预渲染成静态 HTML，可以让整个系统保持简单、快速和可迁移。

## 这套工程做了什么

- Astro + TypeScript 页面与内容层
- Markdown / MDX 文章
- 分类、标签、归档
- RSS、Sitemap、Canonical、Open Graph、JSON-LD
- Pagefind 全文搜索
- 暗黑模式与响应式布局
- Twikoo 评论与 Umami 统计的可选接入
- GitHub Actions CI

## 下一步

把这里的示例文章替换成你自己的内容，然后配置域名、图片 CDN 和动态服务即可。
