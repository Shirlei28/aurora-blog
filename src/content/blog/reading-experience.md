一个博客真正高级的地方，往往不是首页有多少动画，而是打开一篇长文章之后，你愿意继续读下去。

## 阅读路径应该足够安静

标题、摘要、正文、目录之间应该有明确的层级，但不要互相抢注意力。

> 设计阅读体验时，最重要的能力之一，是知道什么时候应该让界面退后一步。

## 代码也应该好读

例如一个最简单的发布脚本：

```bash
npm run check
npm run build
npm run preview
```

它不需要炫技，只需要稳定。

## 最后

好的个人博客不是信息最多的网站，而是一个让人愿意停留的地方。
